# Fonts

Switzer is by Indian Type Foundry, from [Fontshare](https://www.fontshare.com/fonts/switzer), under the ITF Free Font License in `FFL.txt`. The repo's licence does not cover these files.

The licence allows self-hosting on this site. It does not allow making the font files available through a public repository, so remove them before this repo goes public, and do not add them to the registry, the CLI or the npm package. The files must stay unmodified.
